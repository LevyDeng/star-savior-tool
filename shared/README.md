# Shared desktop/mobile contract

`assets/contract.json` contains the schema version, source resource names, languages, difficulty multipliers and default normalized capture regions. `assets/vocabulary.json` exports the desktop vocabulary and is bundled by Android. `fixtures/` contains English synthetic game data and expected matching/conversion outputs generated by the existing Python implementation.

Regenerate with Python 3.11 or later from the repository root:

```text
python shared/tools/export_contract.py
```

After changes to matching, conversion or vocabulary, regenerate and run both platform checks. This does not make the Kotlin and Python implementations identical automatically; golden cases detect covered differences. JSONObject object-key order is not a portable contract. Event identity, ordered choices, effect text and candidate scores are the portable behavior.

The mobile implementation uses the same source format but stores an atomic JSON snapshot rather than the desktop SQLite wrapper. Native capture, OCR, UI and storage remain platform-specific. Card-image matching has only been implemented on Windows.
